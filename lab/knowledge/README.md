# Notas locais autorizadas

Os documentos autorais aprovados devem ser guardados **somente no IALAB**, na pasta `lab/knowledge/approved/` (ignorada pelo Git). Uma nota só entra no índice se iniciar exatamente com `PUBLICACAO_AUTORIZADA: SIM` e incluir uma linha `AUTORIA: Nome`. Isso não constitui auditoria automática de direitos: revisar antes de colocar arquivos na pasta.

Não copiar para cá ROMs, livros, manuais, scans, PDFs, fotografias ou código de terceiros, tampouco conteúdo privado do Drive.
