# RetroAI — SpectrumAI

Plugin de assistência técnica para **TK90X, TK95 e ZX Spectrum**: diagnóstico, circuitos, Z80, ULA, ROM, RAM, vídeo, teclado, restauração e expansões.

**Princípio:** Nada é “funcionou” sem prova. Isole e meça antes de adivinhar.

## Obter o pacote

[Baixar RetroAI-SpectrumAI-v0.1.0.zip](releases/RetroAI-SpectrumAI-v0.1.0.zip)

O ZIP contém manifesto, skill técnico, README e ícone. É uma **reconstrução pública portátil do núcleo técnico**, não uma exportação integral do plugin instalado na conta do autor. Não inclui arquivos privados do Google Drive, credenciais nem documentação de terceiros.

### Como utilizar

- **Diretamente no ChatGPT:** após aprovação e publicação no diretório público de plugins, procurar *RetroAI — SpectrumAI* no catálogo, instalar e selecioná-lo na conversa. A publicação aqui no GitHub não disponibiliza automaticamente o plugin no catálogo.
- **Por ZIP:** ambientes que permitam instalação de plugins a partir de arquivos podem importar o ZIP. Essa função depende do aplicativo e das permissões da conta.
- **No Codex:** use uma instalação compatível com plugins / marketplace Git, quando disponível.

Leia o [guia curto para os leitores](docs/Guia-de-uso-RetroAI.md).

## Exemplo de pergunta

“Meu TK90X mostra tela preta. Como verifico as linhas de energia, o clock e o RESET do Z80, antes de trocar componentes?”

Ao pedir ajuda, informe modelo, revisão, sintomas, alterações, fotos e medições reais.

## Segurança e fontes

As respostas devem separar fatos medidos de hipóteses. Desenergize para reparos e confira sempre a revisão e a pinagem no esquema correto. Cada usuário deve conectar e autorizar seus **próprios** documentos quando desejar consultas externas.
